# Force Phishing-resistant MFA

## Kvifor 
Disse innstillingene styrker sikkerheten ved å begrense brukeres administrative rettighetar

## Korleis
Logg inn i entra (https://entra.microsoft.com) > users > User settings

**Default user role permissions**
* Users can register applications: False
* Restrict non-admin users from creating tenants: True
* Users can create security groups: False

**Guest user access**
* Guest user access restrictions: Guest users have limited access to properties and memberships of directory objects

** Administration center**
* Restrict access to Microsoft Entra admin center: True

**LinkedIn account connections**
* Allow users to connect their work or school account with LinkedIn: True

**Show keep user signed in**
Show keep user signed in: True
