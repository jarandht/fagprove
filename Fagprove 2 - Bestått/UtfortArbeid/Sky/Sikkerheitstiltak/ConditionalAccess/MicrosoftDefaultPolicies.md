# Deaktivere MICROSOFT-MANAGED conditional access polecies

## Kvifor?
Alt er dekka frå før: Eigne CA-policyar er allereie på plass og oppfyller dei same (eller betre) sikkerheitskrava.

Unngå konfliktar: Microsoft sine automatiske policyar kan overlappe eller kollidere med organisasjonens eigendefinerte reglar.

Enklare drift: Ved å bruke berre eigne policyar, får ein betre oversikt, kontroll og enklare vedlikehald.

## Korleis

Logg inn i entra (https://entra.microsoft.com) > Security > Conditiona access > Policies

Trykk på dei som er "Microsoft managed" > Edit

Enable policy: Off
