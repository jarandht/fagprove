## Relevante regler og rammeverk

Kommunar skal følgje NSM sine grunnprinsipp for IKT-sikkerheit, stille krav til leverandørar og ha kontroll på heile leverandørkjeda. Det skal gjerast ROS-analysar og utarbeidast beredskapsplanar for å sikre drift og datatryggleik. Ved bruk av eksterne tenester og datasenter må kommunen stille krav til fysisk og digital tryggleik, og ha plan for handtering av hendingar (t.d. via KommuneCERT).

## Bærekraft tilltak innad i Voss herad
* Ansatt rådgjevar for miljø
* Bygg nye kommunale bygg på miljøvenlege måtar, ved å bruke tre istandenfor betong for eksempel
* Sammarbeider om å gjennbruke utstyr internt på avdelinga og utforsker å kjøpe meir brukt
* Gjev krav til leverandør under innkjøp
* Legg opp til å sykle til jobb med å bygge sykkelparkering
* Kjeldesorterar og sender elektronigg på gjennvinning
* Legg opp for energisparing og planlegg for bygging av solceller på kommunale bygg
